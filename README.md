# Carlos Queirós Seguros | Landing page de demonstração

Site estático em HTML, CSS e JavaScript, pronto para abrir localmente no navegador e publicar num alojamento estático.

## Utilização

Abra `index.html` no navegador. Para publicar, envie `index.html`, `styles.css`, `script.js` e a pasta `assets/` para a raiz do alojamento.

- Fotografias ilustrativas externas carregadas através de URLs do Unsplash. Precisam de ligação à internet; devem ser substituídas por fotografias autorizadas do cliente antes da publicação definitiva.

## Personalização

As cores principais estão no início de `styles.css` em `:root`. Pode substituir a logomarca ou os endereços das fotografias conforme necessário.
